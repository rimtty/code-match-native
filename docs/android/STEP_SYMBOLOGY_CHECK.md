# BLE工程別読取制御

2026-09-05: Androidの非配布scannerPocはQR待機時にQRのみ、Code128待機時にCode128のみを公式Inateck SDKで有効化する。

- 実機が返した全symbologyの識別情報を保持し、対象以外を無効化する。
- 各設定変更は既存のSDK書込・全要求値のfresh readbackを通す。完了前はReadyにしない。
- 設定中の工程変更は最新要求へ集約し、同一工程への再要求は追加書込しない。
- 終了・背景移行時の元設定への完全復元を、保留中の工程変更より優先する。
- timeout後は既存の切断・復元境界を維持する。照明設定の扱いは変更しない。
- iOSは現状の両形式有効化を維持し、変更はIssue #39で別途対応する。

## 実機受入（未実施）

1. QR待機の設定確認完了後、Code128をトリガーで読んでもスキャナーがデコードせず、アプリがエラーを出さない。
2. QRを読むと設定確認を経てCode128待機になる。そこでQRを読んでもデコードしない。
3. 正しいCode128で一致し、次の箱でQRへ戻る。QR読み直しも確認する。
4. 工程切替中の短いトリガー、背景復帰、再接続でも工程・件数を保持する。
5. セッション終了で開始前の全symbologyへ復元する。

設定通信中の入力は受け付けない。切替所要時間と実機のデコード抑止は自動テストだけでは保証しない。

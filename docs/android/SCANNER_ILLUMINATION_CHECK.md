# スキャナー照明の実機確認

対象は公式Inateck Android SDK 2.0.0を使う非配付scannerPocです。

設定画面の照明OFFは常時消灯、ONは読取中点灯です。接続ごとにOFFを適用し、SDKで再取得した値が一致してから確定表示します。SDKのinventoryにある`lighting_lamp_control`のareaを保持します。一般APIのflag 1003をareaへ置き換える推測はしません。

確認手順:

1. 接続後、照明設定の確認が終わりOFFになることを確認する。
2. ONへ変更し、トリガー中に点灯することを確認する。
3. OFFへ変更し、トリガー中にも消灯することを確認する。
4. QR→Code 128で照合し、照明変更後も工程と件数が正しいことを確認する。
5. 設定変更中に背景へ移動し、復帰後に設定失敗や工程消失がないことを確認する。
6. 設定変更中の手動切断、スキャナー電源OFF、再接続を確認する。古い接続の成功表示が新しい接続に混ざらず、再接続ではOFFへ戻ることを確認する。

自動検証はコマンドのidentity保持・値の確認・未対応拒否、保留要求の最新化と順序、および設定画面の操作通知・変更中無効化・確認後ON表示・切断時無効化を対象にします。実SDK通信中の通知の取りこぼし、照明の物理動作、タイムアウト時の完全復元は、この実機手順の結果を記録するまで未検証です。

読取時間延長、周辺コードの狙い撃ち設定、BLE受信の追加改善は別途実装・評価が必要です。この照明変更だけで完了とは扱いません。
